### Featured projects

- [**Settlement Engine**](https://github.com/AidanAlsaadoun1/market-settlement-engine) · [verified on Sepolia](https://sepolia.etherscan.io/address/0x36A7cf4DCD4a722Afc3F0Fd3861729CeF5c8B516)
  **A miniature real-money settlement system, built in a fortnight to learn Go.**
  A Solidity parimutuel market contract emits an event for every state change; a Go service ingests the logs into an append-only PostgreSQL ledger with checkpointed backfill and idempotent writes, and a reconciler continuously compares on-chain state against the database, alerting on drift. Confirmation-depth handling, transient-vs-fatal error taxonomy, crash-safe resumption.

- [**Clarify**](https://github.com/AidanAlsaadoun1/Clarify) · [live](https://clarify-accessibility.vercel.app/)
  **Accessibility-first document summariser.**
  Hackathon-built tool to help students with accessibility needs. Summarises documents, plays the result back as audio via Groq, supports ELI5 mode and key-term search.

- [**Skye**](https://github.com/AidanAlsaadoun1/gym-app) · [skyeapp.fit](https://skyeapp.fit)
  **Gym companion app.**
  Workout tracking app — log sessions, see progression over time, build the habit.

- [**Skyerise**](https://github.com/AidanAlsaadoun1/skyerise) · [skyerise.cloud](https://skyerise.cloud)
  **Sunrise quality forecast.**
  Predicts whether tomorrow's sunrise is worth the alarm clock — so you only get up for the good ones.

- [**aws-profile-switcher**](https://github.com/AidanAlsaadoun1/aws-profile-switcher)
  **Interactive terminal AWS profile switcher.**
  Curses TUI over `~/.aws/config` — preview region, SSO, role, and live account ID before switching `AWS_PROFILE`. Zero runtime dependencies, automatic `.zshrc` backups.
